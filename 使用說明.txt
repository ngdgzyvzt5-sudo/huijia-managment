【V100 私人雲端同步測試版】
1. GitHub Pages 覆蓋全部 10 個檔案後，重新開啟 APP。
2. 維修或專案／樣品 → 設定 → 私人雲端同步。
3. 以 Supabase Authentication → Users 中建立的 Email／密碼登入（不是 GitHub 管理員登入）。
4. 第一台裝置按「上傳本機資料」，確認後會產生本機 JSON 備份。
5. 第二台裝置登入同一帳號，按「下載雲端資料」，確認後也會產生本機 JSON 備份。
6. 後續編輯後需再次手動上傳；另一台需手動下載。V100 尚未開啟背景自動同步。
7. 請勿同時在兩台裝置修改同一張單據；手動同步不會合併衝突內容。
8. 若提示登入錯誤，檢查 Email 是否為 APP 專用帳號，以及 Supabase Authentication 是否允許 Email 登入。
9. 上傳前請確認另一台沒有尚未上傳的新資料，避免被取代。
10. 若資料屬敏感個資，正式投入使用前請另行完成安全審查及資料備份規劃。
